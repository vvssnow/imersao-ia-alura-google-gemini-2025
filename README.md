# 📊 SearchVulnIA: Consulta e Análise de Vulnerabilidade

Bem-vindo ao SearchVulnIA, um projeto de consulta e análise de vulnerabilidade desenvolvido como conclusão da Imersão IA, 3ª Edição, da Alura em parceria com o Google Gemini. O SearchVulnIA é um sistema interativo onde diferentes "Agentes" de segurança colaboram para fornecer informações relevantes e práticas de proteção, baseadas em vulnerabilidades recentes. Este projeto é ideal para profissionais de segurança da informação que desejam se manter atualizados sobre as ameaças atuais na área.

## 🚀 Como Funciona?

O sistema utiliza quatro agentes especialistas que trabalham em conjunto para oferecer uma solução completa:

1. **Agente Consultor 🕵️‍♂️**: Busca as últimas notícias e lançamentos em segurança, focando em vulnerabilidades dos últimos 30 dias.
2. **Agente RedTeam 🔴**: Analisa as informações do Consultor para identificar as vulnerabilidades mais exploradas.
3. **Agente BlueTeam 🔵**: Procura as melhores práticas de defesa e elabora um plano de correção direto.
4. **Agente Auditor 📋**: Por fim, esse agente revisa, formata e apresenta as informações de forma concisa, destacando os principais pontos críticos e recomendações de segurança.

## 📥 Instruções

1. **Inicie a Consulta**: Digite um CVE específico ou o nome de um fornecedor (vendor) para pesquisar vulnerabilidades.
2. **Receba Informações Detalhadas**: O sistema conduzirá você por cada etapa, desde a consulta inicial até a recomendação de ações.
3. **Entenda as Ações Necessárias**: Receba um documento bem estruturado destacando tendências, vulnerabilidades críticas e medidas mitigadoras essenciais.

## 📅 Atualidade Garantida

Utilizando o Google Gemini, o SearchVulnIA assegura o acesso a informações atualizadas, incluindo notícias e dados relevantes dos últimos 30 dias.

## ⭐ Por que Usar?

- **Fácil de Usar**: Interface intuitiva para profissionais de segurança de todos os níveis.
- **Informações Atualizadas**: Acesso a dados recentes e críticos.
- **Colaboração Especializada**: Análises de múltiplas perspectivas por agentes especializados.
- **Conteúdo Rico**: Resultados apresentados de forma clara, técnica e envolvente.
